## Bugs Found and Fixed

### BUG-01 -- Reports nav links 404 (Blocker)

**Flow:** Finance → Reports index
**Root cause:** Report card links used raw `<a href="/app/reports/trial-balance">` -- wrong path prefix, bypassed TanStack Router.
**Fix:** `apps/app/src/routes/_app.reports.index.tsx` -- replaced all `<a href>` with `<Link to>` using correct `/reports/*` paths.
**Commit:** `0879cde`

---

### BUG-02 -- CommunitySwitcher always shows "Select community" (Blocker)

**Flow:** Any authenticated page -- community name never rendered in sidebar
**Root cause:** `useState(communities[0]?.community)` captured the initial empty-array value on mount; async communities data arrived after state was frozen.
**Fix:** `apps/app/src/components/community-switcher.tsx` -- split into `explicit` selection state + computed `active` fallback to `communities[0].community`.
**Commit:** `0879cde`

---

### BUG-03 -- Seed signup silently fails with 403 (Blocker)

**Flow:** Local dev seeding (`pnpm --filter @boardstack/api seed:dev`)
**Root cause:** Better Auth CSRF guard requires an `Origin` header; fetch calls lacked it, returned 403 `MISSING_OR_NULL_ORIGIN`. The error handler treated 403 as "user already exists" and continued silently.
**Fix:** `apps/api/scripts/seed-dev.ts` -- added `Origin: new URL(API).origin` header to all signup requests.
**Commit:** `0879cde`

---

### BUG-04 -- requireTier returns 403 for all seeded users (Blocker)

**Flow:** Reports, Close, Portfolio -- any Scale/Portfolio-gated route
**Root cause:** `requireTier` reads `communities.stripe_price_id`, not `subscriptions.tier`. Seed script set `subscriptions.tier` but left `communities.stripe_price_id = null` → `priceIdToTier(null) = null` → tier check always fails.
**Fix:** `apps/api/scripts/seed-dev.ts` -- added `TIER_PRICE_ID` map and SQL UPDATE to set `communities.stripe_price_id` matching the seeded tier.
**Commit:** `0879cde`

---

### BUG-05 -- Auth errors silently swallowed (Major)

**Flow:** Login/signup with wrong credentials
**Root cause:** `signIn.email` and `signUp.email` (Better Auth client) return `{ data, error }` -- never throw. Code called without `await` in some places; error was not surfaced to UI.
**Fix:** `apps/app/src/lib/auth.ts` -- awaited calls, destructured error, propagated to UI state.
**Commit:** `8fcfa4d`

---

### BUG-06 -- API auth route path mismatch (Blocker)

**Flow:** Login from app → API
**Root cause:** API auth handler mounted at wrong path; requests 404'd.
**Fix:** `apps/api/src/lib/auth.ts` -- corrected Hono route registration path.
**Commit:** `ae7745f`

### BUG-07 -- Dashboard `/settings` link broken (Major)

**Flow:** Dashboard → "Complete setup" → Settings CTA
**Root cause:** Activation checklist used `<a href="/settings">` (full-page navigation), and the Settings route didn't exist.
**Fix:** Created `apps/app/src/routes/_app.settings.tsx` (community name + state form). Updated `_app.tsx` nav. Fixed `_app.dashboard.tsx` to use `<Link to="/settings">`.
**Commit:** `7b1a934`

### BUG-08 -- Homeowners governance page was a stub (Major)

**Flow:** Governance → Homeowners
**Root cause:** Route file contained placeholder content only.
**Fix:** `apps/app/src/routes/_app.governance.homeowners.tsx` -- full implementation: homeowner directory table (name/email/phone/move-in), last-name search, CSV import panel with textarea, import result feedback. Added `api.governance.homeowners.list` and `.import` to `apps/app/src/lib/api.ts`.

---

### BUG-09 -- Marketing nav links 404 (Major)

**Flow:** Marketing site `/compare`, `/resources`, `/hoa-compliance` nav clicks
**Root cause:** Astro configured with `trailingSlash: "always"` -- URLs without trailing slash return 404.
**Fix:** `packages/shared/src/brand.ts` -- added trailing slashes to `NAV_ITEMS` and `FOOTER_LINK_GROUPS` hrefs.
**Commit:** `6f9da0b`
