# Gavelhouse Getting Badges Package

Last verified: 2026-05-15

This folder is the submission package for Gavelhouse on SaaSHub,
AlternativeTo, Product Hunt, G2, and BetaList. Most fields are copy-paste
ready; account-only fields that cannot be verified from the repo are marked
explicitly.

## Submission Order

1. **SaaSHub** - easiest first listing. Use
   [saashub.md](./saashub.md).
2. **AlternativeTo** - add Gavelhouse as an alternative to PayHOA, RunHOA,
   HOA Express, Buildium, and DoorLoop. Use
   [alternativeto.md](./alternativeto.md).
3. **BetaList** - submit only after confirming the "recently launched" story
   is still accurate at submission time. Use [betalist.md](./betalist.md).
4. **G2** - submit after confirming Gavelhouse is not already listed and can
   be treated as available B2B software, not a waitlist or private beta. Use
   [g2.md](./g2.md).
5. **Product Hunt** - submit after the gallery, maker account, and launch
   replies are ready. Use [product-hunt.md](./product-hunt.md).
