New Jersey's reserve balance rule is simple in wording: the balance can never drop below zero.

The board work is in the timing.

A project can be valid. The vendor can be reasonable. The vote can be clean. The funding can still fail if payments hit before reserve contributions arrive.

That is one reason reserve planning has to sit inside the approval workflow. Before the board votes, it should see the reserve balance after the project, not merely the balance on the last statement.
