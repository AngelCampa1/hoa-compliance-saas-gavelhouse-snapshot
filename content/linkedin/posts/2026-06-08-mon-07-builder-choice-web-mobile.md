Gavelhouse does not have a native mobile app yet.

The web interface works on mobile browsers, but that is not the same thing as a native app. Gavelhouse names this as an honest con, and it belongs in the open.

The current product focus is compliance-first board operations: fund separation, reserve deadlines, owner records, governance workflows, audit packets, and month-end close.

For self-managed boards, that foundation matters more than pretending every checkbox is already done.

Build the core operating system first. Be clear about the tradeoffs.
